# Versioning Specification

The complete versioning specification is available in the repository.

See [spec/VERSIONING.md](https://github.com/0din-ai/signature-sdk/blob/main/spec/VERSIONING.md) for:

- Version registry (V0, V1, Latest)
- Compatibility rules
- Migration guidelines
- Future version planning

## Quick Reference

| Version | Status | Model | Dimensions |
|---------|--------|-------|------------|
| V0 | ✅ Stable | text-embedding-3-large | 1536 |
| V1 | ✅ Stable | multilingual-e5-large | 1024 |

**Rule**: Signatures with different versions are **not comparable**.
