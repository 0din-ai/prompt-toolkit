# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this SDK, please report it responsibly:

- **Email:** 0din@0din.ai
- **Do not** open a public GitHub issue for security reports.

We aim to acknowledge reports within 3 business days. Once a fix is available,
we will coordinate disclosure timing with the reporter.

## Supported Versions

Only the latest `0.x` release series receives security fixes. See
[VERSIONING.md](spec/VERSIONING.md) for the version support policy.
